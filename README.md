# Анализ данных компьютерной игры DOTA 2 — дашборд в DataLens

Учебный проект по визуализации данных из компьютерной онлайн-игры **DOTA 2**.  
Цель — построить интерактивный дашборд в **Yandex DataLens**, который помогает  
разобраться в исходах матчей, характеристиках персонажей, предпочтениях игроков  
и их предметных сборках.

## Задачи исследования

1. **Фракции и победы** — как соотносится победа по фракции (светлая / тёмная)?
2. **Тип атаки** — как соотносятся игроки по типу атаки? Какой тип встречается чаще?
3. **Топ персонажей** — какие персонажи входят в топ-10 среди участников матчей?
4. **Топ предметов** — какие предметы игроки приобретают в первую очередь (топ-10 на первой позиции в инвентаре)?
5. **Длительность игр** — как распределяется количество игр по длительности в минутах и сколько игроков в них участвовало? Показать на одном графике.
6. **Характеристики персонажей** — как отличаются средние атака, скорость, восстановление, количество убийств и опыт в минуту у победителей и проигравших в зависимости от ведущей роли выбранного персонажа?

## Данные

Источник — 3 CSV-файла из компьютерной онлайн-игры **DOTA 2**:

| Файл | Описание |
|---|---|
| `matches.csv` | Данные о матчах: длительность, фракция-победитель, тип атаки, роли игроков |
| `heroes.csv` | Справочник персонажей и их характеристики (атака, скорость, восстановление и т. д.) |
| `players.csv` | Данные об игроках в матчах: персонаж, роль, предметы в инвентаре, убийства, опыт в минуту |

Ключевые поля, использованные в дашборде:

| Поле | Описание |
|---|---|
| `match_id` | Идентификатор матча |
| `faction` | Фракция игрока (светлая / тёмная) |
| `winner` | Победитель матча |
| `attack_type` | Тип атаки персонажа (ближний / дальний) |
| `hero_name` | Имя персонажа |
| `role` | Ведущая роль персонажа в матче |
| `item_1` | Первый предмет в инвентаре |
| `duration_min` | Длительность матча в минутах |
| `players_count` | Количество игроков в матче |
| `attack`, `speed`, `regen`, `kills`, `xp_per_min` | Характеристики персонажа |

|---|---|
| ![Распределение матчей](<img src="images/1.png" alt="Дашборд" width="400">) | ![Характеристики персонажей](<img src="images/2.png" alt="Дашборд" width="400">) |



Дашборд собран как единая интерактивная страница с селекторами:

- **Селектор «Фракция»** — фильтрация по светлой / тёмной стороне
- **Селектор «Победитель / проигравший»** — сравнение исходов
- **Селектор «Имя персонажа»** — детализация по конкретному герою
- **Селектор «Нижний игрок»** — фильтрация по позиции в списке

> Синхронизация селекторов **отключена** для визуализаций, где она избыточна  
> (например, там, где фильтрация по персонажу и фракции одновременно искажает картину).

Основные визуализации:

- Соотношение побед по фракциям
- Распределение игроков по типу атаки
- Топ-10 персонажей по числу участников матчей
- Топ-10 первых предметов в инвентаре
- Совмещённый график: длительность игр + количество игроков
- Сводная таблица средних характеристик персонажей у победителей и проигравших
